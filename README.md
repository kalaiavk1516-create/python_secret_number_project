# 🎯 Python Mini Projects

This repository contains three beginner-friendly Python programs:

## 1️⃣ Number Guessing Game
- Random number generated between 1 and 10.
- User has **3 attempts** to guess the number.
- Program gives hints: *Too low* / *Too high*.
- If guessed correctly → 🎉 Congratulations message.
- If not → "Better luck next time!"
